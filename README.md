## 先分清：你要的是"一台云端电脑"，还是"一台云服务器"

**显卡云电脑**：一台带显卡的 Windows 主机放在机房里，你用远程桌面或串流连上去操作。游戏在云端跑，本地只负责显示画面、传回键鼠指令。

**游戏云服务器**：没有桌面，也没有显卡。本质是一台高主频 CPU 的服务器，用来跑 MC 服务端、面板服这一类"开着给别人进"的程序。

判断标准就一句话：游戏里那个跑来跑去的是你自己的角色，你要的是云电脑；那台机器要一直开着等别人连进来，你要的是云服务器。

雨云这家厂商两条线都做。成立于 2018 年，持有工信部颁发的 ISP、IDC、CDN 三类许可证，云服务器、游戏云、裸金属物理机、显卡云电脑都在卖，系统是自研的。下面把两边的价格和适用场景拆开讲。

## 延迟这件事，比参数表更该先想清楚

远程玩游戏绕不开延迟。机房里那台机器再强，画面也得经过你的网络跑一趟，所以真正决定体验的是三样东西：你到机房的物理距离、本地宽带质量、以及你玩的游戏类型。

机房在广东，华南电信、联通用户通常延迟最舒服，华北西北的用户会明显高一截。FPS 竞技类对这点最敏感，手感偏差很难靠心态克服；回合制、MMO、单机 3A、挂机脚本、模拟器多开受影响就小得多。本地网络建议百兆以上，有线优于 Wi-Fi，这一点比选哪家厂商更实在。

第三方测评里，广州那台 RTX 3080 机型的鲁大师综合跑分约 166 万分，其中显卡 67.9 万分，显卡 AI 性能 30.5 万分。这组数字能说明的只有一件事：它跑得动 CUDA 任务和主流游戏。它不是帧数承诺，别拿它当"能满帧跑 4K 光追"的依据。

硬盘扩容另有收费：高速固态 0.4 元/GB/月。机器支持一键部署 1Panel、MCSManager、Cloudreve，也支持 Docker、Java 环境，以及 SillyTavern、AstrBot 这类大模型应用。不少人买它就是当"带显卡的云服务器"用——跑渲染、跑 AI 对话、跑挂机。

## 常见问题

**游戏云电脑和云游戏平台有什么区别？**
云游戏平台只能玩它游戏库里的东西。云电脑是一台完整 Windows，Steam、WeGame 自己装，也能挂机、多开、装别的软件，自由度完全不同。

**关机还收费吗？**
日常网吧型关机不计时不收费；算力长租型是包月占用机器，开不开机都算你租着。

**配置以后能改吗？**
游戏云 VPS 支持 CPU、内存、带宽、硬盘弹性变配，可随时升降级。硬盘扩容高速固态 0.4 元/GB/月。

**数据会丢吗？**
面板服不开机时数据保留 30 天。有退款需求的话，7 天内无理由，每账号 3 次。
